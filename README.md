# KIS
KIS (keep it simple) 
ZIP was created in 1989 — back when floppy disks were the primary storage medium and encryption was
barely an afterthought. For over 30 years, ZIP has been the default choice simply because it's everywhere, not
because it's good. In 2026, that's no longer an acceptable reason.
KIS file was built from the ground up to answer every weakness ZIP has. Its LZMA compression produces files
that are consistently 30–50% smaller than ZIP for the same content. Its AES-256 encryption with 600,000-
iteration PBKDF2 key derivation is orders of magnitude stronger than ZIP's ZipCrypto, which can be cracked in
seconds with free tools.
But the feature that sets KIS file truly apart is encrypted filenames. Even with password-protected ZIP files,
anyone can open the archive and see every filename, folder structure, and file size — revealing exactly what
you're trying to protect. With KIS file, none of that information leaks. The archive is a black box.
If you care about your files — whether personal documents, client data, or sensitive projects — ZIP is not
enough. KIS file gives you compression that's actually worth it, security that's actually secure, and an interface
that's actually pleasant to use
