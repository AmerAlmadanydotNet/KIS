KIS file – Staging Build (1.0.0)

23 / 04 / 2026

Please note that new release 1.0.0 has been published on the Staging environment and it contains the following features and improvements:

Features
  • 🗜
    LZMA Compression Up to 50% better compression ratio than standard ZIP (Deflate). Uses the same algorithm as 7-Zip's .7z format for smaller output files.
  • 🔒
    AES-256-CBC Encryption + PBKDF2-SHA256 Key Derivation (600,000 iterations) Military-grade encryption with a brute-force-resistant key. Each archive uses a unique random salt and IV. Completely uncrackable with current computing power.
  • 🛡
    HMAC-SHA256 Integrity Authentication Encrypt-then-MAC design prevents undetected tampering. Any modification to the encrypted data is immediately detected before decryption.
  • ✅
    SHA-256 Per-file Checksums Every file inside the archive has its own cryptographic checksum. Detects corruption or tampering on individual files, not just the archive as a whole.
  • 🕵
    Encrypted Filenames Optionally encrypt file paths so no metadata is revealed to external tools or scanners. The archive is completely opaque — no one can see what's inside without the password.
  • ✂
    Split Archive Support Split large archives into smaller parts of a configurable size, making them easy to upload, email, or store across multiple drives.
  • 📋
    Full File Metadata Preservation Timestamps (created, modified, accessed) and file attributes are stored and restored exactly, keeping your file history intact.
  • 🖥
    Modern Windows 10 / 11 Native UI Clean, fast interface with drag-and-drop file support, real-time progress tracking, and NavigationView-based navigation. No clutter.
Why I Recommend KIS file

ZIP was created in 1989 — back when floppy disks were the primary storage medium and encryption was barely an afterthought. For over 30 years, ZIP has been the default choice simply because it's everywhere, not because it's good. In 2026, that's no longer an acceptable reason.

KIS file was built from the ground up to answer every weakness ZIP has. Its LZMA compression produces files that are consistently 30–50% smaller than ZIP for the same content. Its AES-256 encryption with 600,000-iteration PBKDF2 key derivation is orders of magnitude stronger than ZIP's ZipCrypto, which can be cracked in seconds with free tools.

But the feature that sets KIS file truly apart is encrypted filenames. Even with password-protected ZIP files, anyone can open the archive and see every filename, folder structure, and file size — revealing exactly what you're trying to protect. With KIS file, none of that information leaks. The archive is a black box.

If you care about your files — whether personal documents, client data, or sensitive projects — ZIP is not enough. KIS file gives you compression that's actually worth it, security that's actually secure, and an interface that's actually pleasant to use.
